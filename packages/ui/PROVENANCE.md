# Axiom design system provenance

All 43 glyph geometries, token values, palettes, scales, semantic roles, and generator code in this package were created for this repository by the project authors.

No third-party icon set, icon font, sprite, logo, illustration, UI kit, or design template is copied, traced, downloaded, or bundled here. The generated `tokens.css`, `icons.svg`, and `favicon.svg` are built only from [`src/tokens.js`](src/tokens.js) and [`src/icons.js`](src/icons.js). The stylesheet loads no webfont or remote asset, and the sprite contains no external references.

Fonts named in the token stacks are not bundled. They resolve to locally installed fonts or documented system fallbacks.

This is an originality and provenance statement, not a legal conclusion. Generic functional symbols such as a folder, search magnifier, or terminal prompt are not claimed as unique.
