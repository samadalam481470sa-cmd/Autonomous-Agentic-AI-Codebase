# Initial threat model
Untrusted prompts, model outputs, workspace files and tool arguments can be adversarial. Path traversal is checked, but symlink races and malicious local files require stronger isolation. Tool calls are not human-reviewed in this MVP. The command tool is disabled by default and **must not** be enabled on shared/public deployments. No authentication, tenancy or network sandbox is provided. Never expose this prototype directly to the internet or connect secrets to untrusted agents. Before production: authentication, per-user authorization, network restrictions, per-job containers, resource limits, secrets vault, approval gates, logging and penetration testing.
