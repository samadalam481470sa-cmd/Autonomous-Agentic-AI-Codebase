# Roadmap

## Milestone 1: Runnable foundation (this commit)
Model gateway, agent tool loop, chat UI, project file tools, local persistence, tests and CI.

## Milestone 2: Engineering workspace
Monaco editor, file diffs, preview builds, resumable jobs, robust tool approval prompts, git branches and pull requests.

## Milestone 3: Safe execution
Replace host shell with ephemeral isolated containers/VMs, cgroups, syscall limits, no host mounts, network allowlists, scoped credentials, cancellation and quotas.

## Milestone 4: Enterprise features
OIDC, RBAC, tenant isolation, encrypted storage, durable queue, distributed workers, audit logging, traces, cost limits, evaluation suite, MCP integrations.

## Milestone 5: Scale
Rust execution controller, Go job scheduler, PostgreSQL/Redis, Kubernetes, load testing, staged rollout.

A million lines is not a release requirement; verified capabilities and security are.
